# WP-13.2 — Rendering honesty: the plate tells the truth about what it draws

*15 September 2026. Phase 13, "the coherent sheet". Cite this report by filename (OQ 90).
Built in six parallel worktrees, one per file region, each measured by the gate rows it owns
(`docs/reports/wp-13.1-the-gate.md`), merged by the lead against the gate, and followed by the
lead's own pass over what the six found in each other's regions.*

## What this package is

WP-13.1's gate read nine things wrong with the sheet Lucas saw. Four of them are the placement's
and belong to WP-13.3 (the prover has been told nothing about the type). The rest are the
RENDERER's: things the record already knew and the plate drew wrong, drew silently, or drew
with a green line saying it had been proved. This package is those, and it needed no ruling —
every fix reads a fact the record carries.

The rule that organised it: **a plate may draw only what the record states, must state what it
could not draw, and may certify nothing it did not prove.**
