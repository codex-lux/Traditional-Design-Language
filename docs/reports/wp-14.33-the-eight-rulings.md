defect was found while it ran. Lucas asked for the remaining questions so the work could be rounded
out. He was asked all eight directly and ruled each on the recommended answer:

question is filed. The register goes from 237 entries with 133 open to 238 with 128 open.**

## II. What was built, ruling by ruling

### R1 — the dining fire (records only)

`kits/tidewater-georgian.kit.json` says *"Hearths are at the gable ends, on the outside walls of
the end rooms"*. The ruling makes that the governing statement over `rooms/dining-room.json`'s
generic *"a fireplace on the interior wall opposite the sideboard"*.

- **Nothing in the data moves**, because both shipped records already follow the kit.
- **The worked house stays refused**, now on a ruled reading of its own facts, and stays the
  guided example. WP-14.28 stays not built.
- **`glossary/guided-example.json`** says what was ruled, and its basis quotes the kit.
- **Items 1 to 3 of the question stay open.** A checker that reports the disagreement needs an
  authored wall field, which no room record carries.

### R2 — a refusal is brick

- **`--refusal` is `var(--brick)`**, the ink `--mark-refused` draws, so the masthead mark and the
  card it links to agree. Violet is `--t4` and nothing else.
- **The atlas's coastline-not-fetched note** was never a refusal, and is set in `--ink`.
- **`src/marks.test.mjs` resolves the tokens from the stylesheet.** It holds the two refusal tokens
  to one ink, that ink to the brick, and every `--t*` away from it. Restoring the violet turns it
  red.

### R3 — a link is ink with a gilt underline

- **`--link` is `--ink`**, at 9.48 : 1 on paper where `--gilt-deep` read 4.09. The gilt moved into
  `--link-underline`, which goes solid `--gilt-deep` on hover.
- **Twelve link-styled elements had set their own gilt text**, found by what they draw rather than
  from a list. Nine drew the link underline and three were anchors overriding the `a` rule. All
  twelve now take `var(--link)`.
- **`src/inks.test.mjs` computes WCAG contrast on four papers.** It refuses a gilt colour on any
  anchor or underline-drawing block in `src`, in both arms of a conditional.
- **Eighteen non-link labels still set `--gilt-deep` as text.** They are named and not moved,
  because the ruling was about links.

### R5 — a corpus fact in app prose is derived or recorded

- **Two corpus facts were typed as prose, and both moved.**
  - **The family tree's absent traditions** are the `missing-peer-trunks` glossary record, which
    quotes the README. The trunks the tree does hold are its own tradition-rank taxa, read off the

  - **The atlas's *"The corpus records where a style arose in prose, not coordinates"*** is the
    `map-positions` record, which quotes `docs/workbench.md`.
- **`src/copy_ratchet.test.mjs` gained a third scanner, PROSE.** It reads JSX text runs of twelve
  or more words and baselines them by `(file, text)` with a class: `voice`, `disclosure` or
  `not-prose`. There is no `corpus` class.
  - **38 rows on this tree: 13 voice, 25 disclosure and no code fragment.** The question's census
    read 48, ten of them code. The reader stops at a `{` that opens more than an interpolation,
    and skips a run carrying an unmistakable code token.
- **Four mutations, all red:** the absent-traditions sentence restored, a blind reader, a `corpus`
  class, and the code filter off.

### R6 — a description is for a reader

- **Parti schema 0.1.0 → 0.2.0** adds an optional `note` for maintainers, which the page does not

- **Two descriptions outside the five were reworded**: `groupings/garage-and-hyphen.json` and

### R8 — a variant id repeats only as a condition

- **`georgian-colonial-american` repeated seventeen variant ids.**
  - **Twelve were conditional.** Each states a variant plainly and again under an `applies_when`,
    for example gambrel as permitted, and as atypical in New England and the Hudson Valley.
  - **Five were not.** Each was a bare row beside a noted one: `order/corinthian` and
    `roof_material/composition-shingle` (permitted beside atypical), `wing_strategy/none`, and two
    `door_surround` pairs of `op` rows.
- **The five bare rows are deleted and the noted rows kept.** The edit was proved to remove exactly
  those rows and change nothing else in the parsed record.
- **`check_kits.py::check_duplicate_variants`** allows a repeat only where every later row carries
  an `applies_when` and no two carry the same one. That rule applies with or without an `op`.
  Across all 159 kits it finds the five and passes the twelve.
- **Measured: 18 of 164 resolved styles move.** The resolver had kept both rows for `corinthian`
  and `composition-shingle`, so a reader taking the first row read *permitted* and one keying by id
  read *atypical*.
  - 6 styles lose the permitted `corinthian` row, and 18 the permitted `composition-shingle` row.
  - 13 lose an identical `wing_strategy/none` row.
  - 7 see `door_surround` in a new order and nothing else.
  - The elevation's three by-id readers already took the last row, so none of their answers moves.
- **Four mutations.** A bare repeat is red and a conditional repeat is green. With the bare branch
  switched off, or the call unwired from `main()`, the tests are red; `check_kits` alone cannot see
  its own wiring.

## III. What was found

- **Three guards were blind on their first run, and each was found by running a mutation, not by
  reading the guard.**
  - The prose fixture's code line was eleven words, one under the threshold, so the code-filter
    mutation was caught only by the tree.
  - The first code-span rule refused only a span holding `.`, `:`, `=` or `(`. A backticked
    `area_range_sf` passed it, although the page prints plain text and a reader sees the backticks
    whatever they hold.
  - The description sweep's module-level join could be set to 0 with every driven test green. A
    structural test now reads the join.
- **A guard pinned a literal line and went red on a correct change.**
  `tests/test_duplicate_keys.py` matched `if _scene_bad or _dup_bad:`, and R6 added its own flag to
  that line. It now reads the final `if` and requires the flag to be named.
- **And `b33b210` was committed over that red test.** The pre-commit run was piped through `tail`,
  and the `&&` chain read `tail`'s exit code. `51e5151` fixes the guard and records the slip. This
  is the rule CLAUDE.md already states for mutation harnesses, broken one layer over.
- **Twelve words is not a clean gap.** The seven-to-eleven band held 37 runs, nearly all status and
  error lines. All were read by hand, and none states a corpus fact.
- **Only `date_range` of a variant's conditions is ever applied**, by `in_period` under `--date`.
  - Across all kits there are 39 `regions` conditions and 15 `construction` ones, and no reader
    applies either.
  - After the cascade, 249 resolved rows read as canonical or forbidden everywhere, over 72
    styles.
  - `none-masonry-reveal`, "the masonry answer" in its own note, resolves canonical on 61 styles,
    clapboard houses among them.
- **`/api/search/index` counts glossary records**, so the two new ones moved its published count
  885 → 887 in four places; `check_counts.py --fix` rewrote them.

- **The eighteen non-link `--gilt-deep` labels** are the same shape as the links but were not in

  workbench's voice. Prose in string constants, props and `.js` modules is not read.
