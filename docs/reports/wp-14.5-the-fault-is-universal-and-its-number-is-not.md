# WP-14.5 — the fault is universal and its number is not

*Cite this report by FILENAME. There are two Phase 9s, two Phase 11s and two Phase 13s; a number
names more than one package here (OQ 90).*

was executed; the other was measured and mostly refused, with the reason for each refusal.

> "(i) `truss-flattened-pitch`'s note asks for a per-style *substitution* … and the ruling was
> `applies_to_styles`, not a band table. Those styles are now **unjudged** on pitch by that test
> rather than wrongly failed, which is the right direction and not the destination; the table is

## II. The table OQ 63 called "the remaining work" was never a research problem

`truss-flattened-pitch`'s note names five bands to substitute. Four reproduce from the styles'
own migrated `roof_pitch_rise_per_12` constraints **to the tenth of a degree**:

    Cape            9:12 - 12:12  ->  36.9 - 45.0    the note says 36.9-45
    Greek Revival   4:12 -  6:12  ->  18.4 - 26.6    the note says 18.4-26.6
    Craftsman       3:12 -  6:12  ->  14.0 - 26.6    the note says 14-26.6
    Prairie         3:12 -  4:12  ->  14.0 - 18.4    the note says 14-18.4
    Tudor Revival  at-least 10:12 ->  39.8 - (open)  the note says 39.8-53.1

**And so does the band the test itself carried**: 33.7–39.8 is `georgian-colonial-american.c02`
(8:12 to 10:12) converted. The whole note is a transcription of data this corpus already held.

**The two halves already met in one place.** `build/elevation.py:2350` DERIVES the
`roof_slope_angle_deg` the fault reads as `round(degrees(atan(pitch/12)), 1)` from the style's own
constraint. Measured: **a style supplies a pitch measurement exactly when it states a band — 15
and 15, 26 and 26, no exceptions.** So the fault was deriving a number from one record and judging
it against another tradition's.

**The fifth band is the finding and is not closed.** `tudor-revival`'s constraint is
`at-least 10:12`, open above: its 39.8 lower reproduces and the note's **53.1 upper is in no
record in this corpus**. Under the substitution a Tudor is judged open above, which is what its own
node says, and 53.1 is not invented into the data.

## III. What was built: `band_from_style`, and why not 48 copies

The obvious execution of the note is a `secondary_tests` entry per style. 48 of 164 styles carry
the constraint, so that is **48 second spellings of a number the style node already states**,
going stale the moment a constraint moves — the defect `build/check_addresses.py` exists for, at
scale. It was refused.

Instead the TEST declares that it wants the style's own band and the engine reads it. One optional
field on the shared test object (`schema/fault.schema.json`, `/properties/test`, which
`secondary_tests` and `exceptions[].bounds_test` both `$ref`, so one addition covers all three
locations):

```json
"band_from_style": { "expression": "roof_pitch_rise_per_12",
                     "convert": "rise_per_12_to_degrees" }
```

Five things about it are load-bearing:

1. **`threshold` and `upper` MUST BE ABSENT**, enforced by the schema. One quantity keeps one
   number per style; a test carrying both would be the stale copy this field removes.
2. **The DIRECTION comes from the style too.** `at-least 10:12` stays open above rather than
   acquiring an upper bound nobody wrote. `at-most` moves its number into `threshold`, because
   the evaluator reads `threshold` for every direction but `between`.
3. **A style stating no such constraint is NOT RUN** — the same three-state discipline
   `applies_to_styles` and `applies_when` use, and never a fall-back to the band written for
   somebody else. Not run is not a pass.
4. **The conversion table is CLOSED**, on `build/construction_vocabulary.py`'s precedent
   (`core.BAND_CONVERSIONS`, one member). An unknown name is an **error**, never an identity: an
   identity would compare degrees against rise-in-12 and convict every house on earth.
5. **The substitution is made in a COPY.** `_data()` is cached and shared, so rebanding the record
   in place would make the first style's band the corpus's band for every caller after it —
   silently, and in whichever order the styles happened to be visited.

The band carries its provenance (`band_from`: the style, the rule id, the expression), because a
substituted band that does not say where it came from is a number with no author, which is the
whole complaint against the band it replaced.

**And the record states no `direction` either.** A first draft left `"direction": "between"` in
the fault as a placeholder the engine always overwrites — which is false of `tudor-revival`, whose
band is open above, and is the second-spelling defect in miniature inside the field built to
remove it. Removed.

**The schema and the checker refuse the same three fields, which they did not at first.** The
schema's conditional forbade `threshold` and `upper`; `check_faults.py` forbade those and
`direction`. Two guards for one rule disagreeing about its scope is the shape this corpus
criticises everywhere else, so `direction` is in both now — and the mutation proves both fire on
it. The checker exists beside the schema because the schema is only checked where `jsonschema` is
installed, and a tree without it must get the same answer.

**`check_faults.check_test` reached two of the three test locations, and widening it cost
nothing.** It ran on `test` and `exceptions[].bounds_test` and never on `secondary_tests` — a
guard reaching two thirds of its subject, whose silence therefore means less than a reader thinks.
**Measured before it was widened: of the corpus's 273 secondary tests, exactly ZERO warn or error
under it**, so the widening is free and is in. Three mutations bite it: a band asked for and
stated (caught twice, by the schema and by the checker), a direction stated beside the ask, and a
secondary with no threshold — the last being the case that was invisible before.

**The reader is not a fourth spelling of `_style_roof_pitch`.** That function is spelled in
`build/structure.py`, `build/roof.py` and `build/depth_floor.py`, and CLAUDE.md's standing
instruction is *"Do not add a fourth without extending that test."* `core.style_band` answers a
**different question** — those three return a representative VALUE (the midpoint of a `between`)
and this returns the BAND — and the two are held together by arithmetic over all 164 styles in
`tests/test_fault_thresholds.py`, which is the mechanism the instruction asks for.
`build/fault_thresholds.py` DELEGATES rather than respelling, and a test asserts the delegation:
a diagnostic walking the constraint list itself could report a band the engine does not use, which
would be this package's own defect committed by its own instrument.

## V. Deferral (ii), the primary sweep: measured, and mostly refused

> "(ii) **The same pattern exists on PRIMARY tests** … but scoping them is a data sweep over 209
> faults, not six. … That sweep wants its own package."

**0 of 210 primary tests carry `applies_to_styles`, and none was given one.**

`build/fault_thresholds.py` is the instrument — a report-only CLI on `build/detection.py`'s
precedent, **not in `check_all.CHECKS`**, so `TOTAL_CHECKS` stays 53. It reports three buckets and
never two: `evidenced` (the corpus already states this style's own figure — a finding),
`no_second_number` (universal because nobody wrote another — a research gap convicting nothing),
and the names its join table has not been asked about. Collapsing the second into the first is what
ruling 2 forbids.

    THE CENSUS IS OVER 41 OF 164 STYLES. The other 123 supply no measurement at all
    and are UNJUDGED, not clean.
      conviction rows            944
        deciding on a PRIMARY    642
        deciding on a secondary  293
        deciding on a bounds_test  9
      EVIDENCED                   17
      NO SECOND NUMBER           927   (reported, convicting nothing)
      names the join table does not reach: 41; refused with a stated reason: 2

**All 17 evidenced rows are two faults, and neither may be scoped or substituted.**

- **`pitch-below-material-shed-limit` (14 rows) states a floor per MATERIAL, not per tradition.**
  Its own note: *"Apply the material's own historic minimum, not the code's: wood shingle 26.6
  deg, wood shake 26.6, slate 33.7, flat clay tile 40."* A lapped shingle roof below its natural
  slope leaks whatever tradition built it, so **substituting the style's pitch band here would be
  lowering a threshold to make a style clean**, which this package's own plan forbids. The real
  defect is one axis over: the fault runs the wood-shingle floor AND the slate floor against every
  house at once, and **99 of 164 styles resolve a canonical `roof_material` the fault reads none
  of**. Four of the eight slate-floor convictions are on styles whose own kit makes wood shingle
  canonical. `oq/the-material-shed-limit-runs-every-material-against-every-house`.
- **`raised-cape-eave` (3 rows) carries a type-defining band that contradicts nine styles**,
  including `cape-cod-revival`, one of the two its `severity_by_style` calls fatal, and
  `minimal-traditional`, which it names in `applies_to`. Substituting would make the band vacuous
  on the very styles the fault is for. `oq/the-cape-pitch-band-contradicts-nine-styles-own-bands`.

**The other 927 have no second number anywhere in the corpus.** They are the honest residue of the
deferral: the *fault* is universal and its *number* is not, and the corpus does not hold another
number to put in its place. Reporting them is the deliverable; inventing bands for them is what
ruling 2 exists to prevent.

**And OQ 63's own named example is not a live case, which only running it showed.**
`gutter-as-cornice`'s primary is a plane-change COUNT and it is **clear on 40 of the 41 judged
styles**; the single conviction is `minimal-traditional` on an exception's `bounds_test` about
casing width, not the cornice projection. The 7 in figure is `secondary_tests[0]` and no style in
this corpus states a cornice projection to substitute. The argument stands; the instance does not.
Corrected in OQ 63's own entry rather than left to be re-read.

## VI. The denominator, stated rather than hidden

**The census is over 41 of 164 styles.** The other 123 return `applicable: false` from
`build/elevation.py` naming their own reason — outside `opening-proportion`'s and/or
`facade-classical`'s calibration — and are **wholly unjudged**: median 184 unjudged, 0 clear, 0
present, 0 measurements. A census that counted them as clean would be the fake-pass direction at
corpus scale, so the CLI prints the denominator in its first line and `--refusals` names all 123.
`tests/test_fault_thresholds.py` asserts 41 and 164 so the denominator cannot quietly widen.

**The discriminator was ruled and a naive one was refused.** **Fourteen faults convict 41 of 41
styles** — the figure carried into this package's own planning was SEVEN, and re-deriving it on
the settled tree is how that was caught, which is this corpus's own rule met inside the package
written about numbers that nobody re-derives. It is NOT evidence of a one-tradition number: with the measurements held constant it is
equally consistent with the house genuinely having the fault —
`storeys-out-of-vertical-alignment` is one this corpus already records firing at 38.556 in against
2.0. Ruling of 20 Sep 2026: **a threshold is convicted only where the corpus ALREADY holds a
style-specific figure for the same quantity.** No band was invented.

**The join is the hard part and it is a closed table.** A fault test reads `roof_slope_angle_deg`;
the style states `roof_pitch_rise_per_12`. Two names, one quantity, and no name match finds it —
OQ 48's problem one layer out. `QUANTITY_JOIN` is authored, explicit and closed: each entry says
which two names mean one quantity, how to convert, and **why they are one quantity** — the part a
machine cannot supply and the part that makes an entry admissible. Two expressions are refused
with a stated reason (`roof_height_eave_to_ridge` and `wall_height_grade_to_eave`: a roof's height
over its wall depends on the SPAN too, so a per-style pitch does not determine it, and that fault's
primary is deliberately the style-independent form). 41 more names are reported as not-yet-asked,
which is a different fact from *no second number exists*.

## VIII. What was deliberately not done

- **No threshold was lowered, no band widened, no rule loosened to make a style clean.** This
  package changed what a measurement DECIDES, never the standard.
- **No band was invented**, 53.1 included.
- **The 123 declining styles are not counted as clean**, in any table, at any point.
- **No primary test was scoped.** The sweep was run and it found 17 evidenced rows in two faults,
  both of which need a ruling before anything is scoped or substituted.
- **`plan_check`'s `[0]`** was not changed: all three available answers move a pinned digest and
  two move a composer score, and picking one on a session's reading is the move this corpus
  refuses.
- **`_style_chain` was not narrowed.** It is `_applies`'s reader too — it decides which styles a
  whole FAULT reaches — so narrowing it would silently un-apply faults nobody is asking about.
