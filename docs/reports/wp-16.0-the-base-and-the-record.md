## III. What was found

- **The workflow said the CAD selftests run in the workbench job, and they ran in no job.**
  `ci.yml` read: *"their selftests are exercised in the workbench job, which installs them."* That
  job installs both libraries and runs only the server suite, the smoke test and the walk. The
  comment is corrected in place.
- **One option put to Lucas carried a false clause.** The fault-verdict question said
  *"no ranking moves by itself"*. The planning review found that `compose.py`'s solecism share
  (clear / (clear + present), weight 20) can reorder candidates with equal fatal counts. The
  correction is dated in the question's own file, and WP-16.1 measures the reordering.
- **Two figures published about decision 4 are the census's attribution, not the corpus's.**
  - The census names the nearest `extends` delta as a ban's source, not the node that wrote the ban.
    So its "own / inherited / both" split is a statement about the resolver.
  - The planning pass traced the gable-return bans on eight shipped plans to
    `gothic-revival-american`'s bargeboard rule, not to colonial-revival.

  Both are recorded in the decision-4 and gable questions. WP-16.2 re-derives them before any
  figure is pinned.
