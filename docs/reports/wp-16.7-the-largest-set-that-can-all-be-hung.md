# WP-16.7 — The largest set of shutters that can all be hung

*Phase 16, 1 October 2026. R7: a refused pair no longer blocks its neighbour. The largest set of
leaves that can all be hung is hung; among equal sets, the one symmetric about the face's centre
line, then the one nearest the entrance or the face's centre.*

## I. What was asked

Lucas's ruling of 29 September 2026, asked as a direct question and recorded in
`oq/a-leaf-refused-for-a-neighbour-that-is-itself-refused`:

> A refused pair no longer blocks its neighbour. Among equally good sets, prefer one symmetric
> about the front's centre line, then work outward from the entrance, so a symmetric front never
> keeps shutters on one side only.

Two readings were recorded beside the ruling the same day: on a face with no seated entrance the
centre of composition is the face's own centre, as the pier ruling reads it; and the symmetry
tolerance is `axis.mirror`'s, so that there is one spelling.

**Taken as recommended under Lucas's standing instruction of 1 Oct 2026, never put.** The
instruction was given at 00:42 UTC: *"Proceed with all recommended answers for all future questions
in this session"*. The code met three choices the ruling's words did not settle:

- **U5, where no largest set is symmetric.** The set breaking the fewest mirror pairs is taken: the
  ruling's preference graded, so a front that cannot be symmetric is made as nearly so as it can
  be. The alternative was to let the symmetry key fall silent and the outward key decide.
- **U6, where the ruled keys do not decide.** Two windows mirrored about the centre, too close to
  hang both, stand at one distance from it, so count, symmetry and distance all tie. The order along
  the face, from its left as drawn, decides. It is a key for determinism alone, which no ruling
  states, and every window it decides says so (§II.4).
- **U7, the bound.** Each group of contending windows is searched whole up to 16 windows. Past it,
  the group's pairs are refused as composed, the rule before this package, under their own class,
  `bound`, which every surface says.

Two more readings are stated rather than chosen:

- **A face with no width has no centre line.** The symmetry key is then not judged, and where it
  could have decided, the windows carry `shutters_symmetry_unjudged`, which the sheet says. Where no
  entrance is drawn either, there is no centre of composition, and the order decides, saying so.
- **The centre line is the face's own**, the main block's face the elevation draws.

## II. What was built

**1. `elevation._clearances`, step 2.** What no choice can give is refused first, as before: a leaf
over another opening as it is drawn, or past the corner of the face. That is the question's own
method ("a window refused for an opening or for a corner cannot keep its leaves in any order"), and
such a window's leaves now stand in nobody's way. Leaf against leaf is a choice, made once for the
face by `_hang`.

**2. `elevation._hang`.** Over the windows left, a set is hangable where no two of its windows'
leaves lie over one another. The set drawn is the best by four keys, in order:

| key | | its standing |
|---|---|---|
| `count` | the most windows | ruled |
| `symmetry` | the fewest mirror pairs broken about the face's centre line | ruled; graded where no set is symmetric (U5) |
| `outward` | the most windows hung nearest the centre of composition, class by class of equal distance | ruled |
| `face-order` | the windows earlier along the face, from its left as drawn | not ruled (U6) |

- **A mirror pair** is two windows on one storey within `axis.MIRROR_TOL_FT` (1.0 ft) of each
  other's reflection about the face's centre line. A window on the centre line is its own mirror and
  breaks nothing. The tolerance is lifted out of `axis.mirror`'s default, so the shutters the
  elevation hangs and the mirror the drawn layer judges read one figure.
- **The search is exhaustive and decomposes by group.** A window whose leaves meet nobody's is in
  every best set. The rest fall into groups joined by a clash or a mirror pair, and each group is
  enumerated whole. The count and the broken pairs are sums over groups, and the last two keys
  compare coordinates that each belong to one group, so the face's best set is each group's best
  set taken together.
- **The bound, `SHUTTER_GROUP_BOUND` = 16 (U7).** At the bound the search costs 0.2 to 0.4 s a
  face, measured on hand-built faces: a run of sixteen windows each too close to the next, and two
  mirrored runs of eight. No sheet in the corpus has a contending group now. On the placement
  before WP-16.6 the largest was four windows: two clashing pairs, each the other's mirror.

**3. `elevation.composition_centre`.** The centre the outward key works from: the entrance where the
face dresses one, otherwise the face's centre. A garage door is no entrance, the placer's own
reading (U4, WP-16.6). The pier floor and the shutters read one centre now.

**4. The record and the words.**
- **A refusal names only neighbours whose leaves are hung.** Past the bound, where nothing was
  chosen, it names every neighbour, as before.
- **Every contended window carries `shutters_decided_by`**: the first key at which the set drawn
  beats the best set that would have done otherwise for it. A refused window carries the reason in
  its key's words.
- **The sheet and the DXF read one spelling** (`elevation.face_notes`):
  - the refusal's line now says the rule: *"ITS LEAVES AND A HUNG NEIGHBOUR’S WOULD LIE OVER ONE
    ANOTHER ... AND WHERE NOT EVERY PAIR CAN BE HUNG THE MOST THAT CAN BE ARE, A SYMMETRIC SET
    FIRST, THEN THOSE NEAREST THE ENTRANCE"* (or the face's centre);
  - *"SHUTTERS CHOSEN BY ORDER ALONG THE FACE ON n WINDOW(S)"* names the rooms the order decided;
  - *"SHUTTER SYMMETRY NOT JUDGED ON n WINDOW(S)"* where the face states no width;
  - the bound's own class says the set was not searched.
- **The scene draws the leaves the same rects carry**, so one choice reaches the sheet, the DXF's
  words and the model.

**5. Census V27.** A window refused its leaves for a neighbour's must stand beside a leaf the sheet
draws, and the order line is held to the record both ways, with its count. Its population is every
sheet that draws a leaf, refuses one for a leaf, or chooses or says an order: 63 rows, all agreeing.
The census is 76 checks.

**6. A committed instrument, `tests/shutter_sets.py`.** It re-derives the question's three columns
on any tree: refused as composed, refused in one pass along the face, and refused by the record. The
question's own probe was never committed.

## IV. What was found

**1. What R7 does where it has something to do.** The rule was laid over the placement before
WP-16.6 (`bb3c6de` with this package's two changed modules), where 82 pairs contend:
- it refuses 111 of the 255 leaved windows, against 193, so 82 windows keep leaves that the old rule
  refused for a neighbour's leaves that were never drawn;
- a tie-break decided on 43 sheets. Of the 164 contended windows, `outward` decided 162 and
  `symmetry` 2. `face-order` decided none;
- **symmetry held everywhere it could.** The contended windows fell into 39 groups of four, each
  two clashing pairs mirrored about the centre, and 4 lone pairs. All 39 groups of four were hung
  symmetrically. Their windows record `outward` and not `symmetry`, because the key a window
  records is the first at which the set drawn beats the best set that would have done otherwise
  for it, and that set was symmetric too. So `outward` on a window does not mean symmetry played
  no part: it chose among the symmetric sets;
- **an independent count agrees**: an exhaustive maximum-independent-set search written for this
  check, over the same clash graph, finds 111 refused and 43 sheets with more than one largest set.
  Those are the figures the question published, 82 and 43, on a later placement. Both columns had
  fallen by the same 39 between 27 Sep and `bb3c6de`, for causes this package did not measure, so
  the 82 the ruling decides are untouched by them.

**2. A string constant in `elevation.py` is a claim about the kit.** The fourth key was first named
`order`. `check_research.generator_read_slots` reads this file's string constants as the slots it
reads, and `order` is a kit slot, so the census's kit-note population grew by three rows and
`plate_review` reported three new N0 rows. The key is `face-order`, with a comment saying why.

**3. V27's first population was empty on the corpus**, because no shipped sheet refuses a leaf for a
leaf any more. It is every sheet that draws a leaf now, and the refusal is driven: good-05's west
face with each room's two sashes a pier of 1.5 leaves apart, wider than one leaf so neither leaf
reaches the other window's glass, and narrower than two so the pair cannot both be hung.

The plan expected V20's and V22's driven specimens to need re-planting, and neither did. They
drive good-05's west face at the foot the placer kept before WP-16.6, where a 23.5 in leaf in a

R7 leaves the specimen as it was, every window refused for an opening.

**4. A guard counted a check it does not drive.** V27's planted drawing, every drawn leaf removed
while the refusals stand, is the one V20 cannot see: an absent leaf overlaps nothing. The first test
