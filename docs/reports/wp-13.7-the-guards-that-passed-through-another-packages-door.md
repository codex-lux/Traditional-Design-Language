## VII. The audit's own errors, recorded because they are the method

1. **A probe reported a containment of 0 over an EMPTY dict.** `geometry.solve()` RETURNS the
   placed record — there is no `"plan"` key — and the first probe read `.get("plan") or {}`.
   Its PREMISE assertion (rooms carrying a `block` tag) is the only reason that was caught; the
   second run then read `length_ft` where the record says `depth_ft` and reported 0 rooms, caught
   by the same assertion. *Before believing a meter's zero, make it report non-zero once.*
2. **A manual restore matched a second occurrence and damaged a scratch tree.** Restoring a
   mutation by replacing two rule ids also hit the `executed` list, taking it 17 → 16; every
   figure taken after it would have been meaningless. Caught by comparing a checker's output
   against the pristine archive. The harness-driven mutations restore from ORIGINAL BYTES and
   verify the hash, and none of them drifted.
3. **Two suites ran concurrently in one checkout for about eight minutes** — the hazard
   `check_all`'s own sharding note describes. Killed, the tree verified clean, and every figure
   re-derived afterwards on a quiet `git archive` of `86bc607`, which reproduced 645 / 155 to the
   unit.
4. **A wrapper's exit code is not the runner's.** The first baseline reported "exit code 0" while
   pytest had errored on an unknown flag and run nothing.
5. **One mutation was semantically a no-op** (a comment added to a counter line) and its GREEN
   proves nothing; it is not counted among the thirty-four.
