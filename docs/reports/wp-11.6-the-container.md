*Phase 11, package 6 of 11. 4 September 2026. From

## The instrument first, and two of its probes were wrong

The ruling says the disclosure "names six layers today and must name five, then four, then none —
a falling count, in the record, is how this ruling is checked rather than claimed". A falling count
is only evidence if the underlying defect is measured independently, so it is:

| layer | probe | baseline |
|---|---|---|
| openings | dependency openings refused | **9 of 14** |
| structure | dependency partition inside the main wall set / the dependency's own envelope walls | **1 / 0 of 2** |
| vertical_score | upper edges credited to a dependency-only wall line | **0 — NOT REPRODUCED** |
| lot_cap | built extent over the lot, uncapped | **24 ft over an 80 ft lot, `lot_capped: null`** |
| plan_check.drawn | dependency rooms convicted of reaching no exterior wall | **2** |
| export_ifc | dependency rooms off the slab | **3** |

The fixture is the Tidewater plan with its kitchen, pantry and breakfast room tagged into a west
dependency — `tests/test_geometry.py`'s own fixture, deliberately, because two files measuring two
different dependencies would be two houses.

**TWO PROBES READ ZERO ON THE FIRST RUN AND NEITHER ZERO WAS A DEFECT'S ABSENCE.** The openings
probe looked for a window drawn far from its room and found none, because the real defect is a
window **refused outright** — every dependency opening came back *"the placement puts this room on
no such boundary wall"*. The structure probe read a `bearing_lines_x` key that does not exist; the
section carries `walls` with a `position_ft`, and a missing key returns nothing. **A probe pointed
at the wrong defect and a probe reading a missing key both report 0, and 0 reads as
nothing-wrong** — the same shape as the stacking meter's missing `vertical` key one package
earlier, twice in two packages.

Two of the six still read zero and both say why rather than counting as clean: the lot probe reads
0 honestly on the reference plan's own 140 ft lot, where the 104 ft built extent fits, and needed
an 80 ft lot to fire; `vertical_score`'s defect does not reproduce on this fixture at all, because
no upper room's edge falls within 0.75 ft of a dependency line, and it is recorded as **NOT
REPRODUCED** rather than as absent.

## Layer 1 — `openings`

**First, and not by preference.** The ruling: an element-aware `openings` makes the dependency's
windows real, which turns `structure`'s missing envelope walls into a **drawn collision** rather
than a silent absence. Fixing them the other way round leaves the shield in place — WP-7.4's
fixture packer, where turning the corner produced five overlapping pairs immediately because the
fixtures had previously been wrong together.

`openings.envelopes()` maps each room to its own element's rectangle and `_boundary_walls` tests
against that instead of the main block. Refused dependency openings **9 → 5**.

**The five that remain are honest.** The kitchen's north edge is 23.72 against its element's 29.12:
it does not reach that face and the refusal is correct. That is the difference between a house
telling you something and an instrument telling you about itself.

**THE OLD READING DID NOT LOSE THE DEPENDENCY'S WALLS — IT ASSERTED ONE FORTY-ONE FEET AWAY.**
`x <= tol` is satisfied by any x at or west of 0.6, so a room at x = −41 tested as sitting on the
main block's **west face**. Against the main block the fixture's kitchen returns `{"W": (9.05,
23.72)}`, not `{}`. That is the mechanism behind the entry's *"a window drawn fourteen feet from
the room"*, and it is worse than reporting nothing: a false positive rather than a silence. This
report's first draft asserted the old call returned nothing, and the test that pinned it failed —
which is the only reason the sharper statement is here.

**The join is the room's own `block` tag, not a room list on the block.** `blocks_record` writes
id, role, x, y, width, depth and area and **no membership**, so a first version read `b["rooms"]`,
found nothing on every plan, and left all nine refusals in place while reporting success. The tag
is what the placer itself groups on, so reading it keeps one spelling of what an element contains.

**The one-rectangle regression holds by construction.** `envelopes()` returns an empty map below
two elements, so every caller falls back to the main block. Both shipped plans place identically —
scores 685.3 and 592.3, declared stacking claims and transfer counts unmoved.

**The disclosure is at five**: `structure`, `vertical_score`, `lot_cap`, `plan_check.drawn`,
`export_ifc`.
