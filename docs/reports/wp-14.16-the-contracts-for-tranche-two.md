## II. What the surveys found that shaped the contracts

These were measured or read on `c1c88f5`. Each is a reason for a line in the PRD.

1. **The two kit resolvers disagree.** `core.resolve_kit` is a hand-merge, and `core._resolved_kit`
   calls the build's `resolve_slots`, which reads inline node kits and OQ 58's scope. Compared on
   binding, canonical and forbidden, they differ on **38 of 15,908 (style, slot) pairs**. The MCP
   `tdl_resolve_kit` and `/api/kit` serve the first; the dossier's count reads the second. Comparing
   two styles needs one authority, so WP-14.26 rebases the first on the second and names every pair
   that moves.
2. **Export can only ever produce the entrance elevation.** `ExportDetails` never sends `face`,
   although both server routes forward it. The Drawing Set's sheet and face live in component
   state. That is WP-14.27's face picker.
3. **`--t3`, a tradition's colour, is byte-identical to `--brick`, the UI's "fatal"** (both
   `#AF6B50`). Of the existing inks, `--salmon` differs from it most, at 1.89 : 1.
4. **The link ink falls short of the common legibility floor on every ground** (4.09 : 1 on paper).
   Tranche 2 changes no ink's value, so this is filed rather than fixed.
5. **The assistant's prompt is stale in three ways**, and so is the prose it loads as tool
   descriptions:
   - it calls itself *"the rail"*;
   - it types *"209"* fault causes where there are 210;
   - it lists no `term`, `brief` or `asset` citation kind, although the validator accepts all three.

   `mcp_server/server.py` repeats the 209 twice, `tools.py` says 26 tools against 27, and
   `candidate_summaries` is read by the server and sent by nobody.
6. **The drawable-plan helper is not in `build/`.** It is `workbench/server/tests/drawable.py`, and
   the verdict it reads is `build/typefacts.py`'s. WP-14.21's method names both.
7. **The proportion-pack schema carries no `version` key.** So "a schema bump" for `axis` and
   `zones` means new optional fields, held by `check_orders.py`, which already sums every pack's
   assemblies.
8. **`core.list_partis` and the composer disagree about which partis belong to a style.** The first
   takes an exact match. The second also credits lineage, and "borrowed" exists only as a sentence
   in a `why`. WP-14.19 makes `compose.nativity` the one spelling.
