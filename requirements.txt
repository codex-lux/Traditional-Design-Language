# Traditional Design Language — Python dependencies
#
# The corpus and every checker in build/ run on the standard library alone, and
# that property is deliberate: a collaborator can clone the repo and validate the
# data without installing anything. What follows is what the tooling *above* the
# data needs.
#
# python3 -m pip install -r requirements.txt

# WP-2.3's constraint solver (build/geometry_cp.py). Optional at runtime: it is imported
# inside solve() rather than at module load, and when it is absent the solver falls
# back to build/geometry.py's heuristic and SAYS SO in geometry_report.solver --
# `{"engine": "heuristic", "reason": "ortools is not installed ..."}`. (This comment said
# the engine string was "heuristic-fallback" until WP-6.4; the code has always written
# "heuristic" plus a reason. The substance was honoured and the token was wrong, which is
# how a reader comes to test for a string that never appears.) A silent fallback would be
# a lie about how the plan was placed. Since WP-6.3 CP-SAT is the DEFAULT rather than an
# explicit act, so an install without it takes the labelled fallback on every drawing.
#
# The floor is >=9.15 here and >=9.8 in workbench/requirements.txt, deliberately: the
# Docker image installs only the workbench file, and the workbench has run on 9.8 in
# production. Raise the workbench floor before relying on anything newer than 9.8 in
# build/geometry_cp.py.
ortools>=9.15

# build/compose.py validates briefs against schema/brief.schema.json on the CLI path.
jsonschema>=4.0

# The behaviour suite; build/check_all.py shells out to it as its last check.
pytest>=7.0

# build/gen_sheet_font.py, and NOTHING ELSE (WP-11.5). The sheet's serif is subset and
# committed under assets/generated/, so the renderers read base64 and a JSON sidecar and
# need nothing at all -- `tests/test_sheet_font.py::test_nothing_at_render_time_imports_
# fontTools` walks the five renderer sources to keep it that way. This is here so a
# maintainer who wants to re-cut the face after an upstream release can, and it is the one
# dependency in this file that no check, no test and no drawing requires.
fontTools>=4.40
